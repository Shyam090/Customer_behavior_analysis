# 🛍️ Customer Shopping Behaviour Analysis

## 📌 Overview

Customer Shopping Behaviour Analysis is an end-to-end data analytics project that analyzes customer purchasing patterns, spending behaviour, discounts, product categories, and customer demographics.

The project covers the complete analytics workflow:

- Loading and exploring data using Python
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- SQL analysis using PostgreSQL
- Interactive Power BI dashboard
- Analytical report
- Project presentation using Gamma

The goal of this project is to convert raw customer data into meaningful business insights that can support better decision-making.

---

## 📊 Dataset

The project uses a customer shopping behaviour dataset containing information about:

- Customer ID
- Age
- Gender
- Item Purchased
- Category
- Purchase Amount
- Location
- Size
- Color
- Season
- Review Rating
- Subscription Status
- Shipping Type
- Discount Applied
- Promo Code Used
- Previous Purchases
- Payment Method
- Frequency of Purchases
